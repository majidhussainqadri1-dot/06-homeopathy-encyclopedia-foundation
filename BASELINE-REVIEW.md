# Mandatory Baseline Review — File 06

The baseline import preserves the supplied source; it is not an approval of the implementation.

Before merge or deployment, review and test at least the following areas:

1. WordPress activation, deactivation, migration, rollback, and uninstall behavior.
2. Required dependencies on Files 00–05 and File 20, including safe failure modes.
3. Custom post types, taxonomies, database tables, rewrite rules, and managed pages.
4. Founder, verified-doctor, reviewer, administrator, patient, student, and guest permissions.
5. Entry submission, validation, review, approval, rejection, correction, report, and audit workflows.
6. References, red flags, safety limitations, related entries, learning books, and lessons.
7. Bookmarks, Saved Knowledge, view counts, comments, privacy export, and erasure.
8. Nonces, capability checks, sanitization, escaping, SQL safety, uploads, and output rendering.
9. Search, A–Z browsing, filters, pagination, popular/latest ordering, and empty states.
10. File 20 Unified Application Shell integration and avoidance of global WordPress regressions.
11. Accessibility, keyboard operation, responsive layouts, localization, SEO, and structured data.
12. WordPress 7.0.x, PHP 8.3, caching, multisite, and real authenticated staging acceptance.

Any defect discovered during this review blocks progression until it is fully corrected, independently rechecked, and accepted.
