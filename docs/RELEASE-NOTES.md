# File 06 — Release Notes 2.0.0

This candidate upgrades the encyclopedia from a moderated WordPress content foundation into the platform’s canonical knowledge and research authority. It introduces permanent concept identity, aliases and redirects, structured sources, immutable versions, integrity notices, duplicate merging, a typed knowledge graph, research and successful-case governance, restricted dataset access, versioned APIs, reliable events, cross-file adapters, privacy lifecycle controls, safe mode, repair and deterministic release evidence.

The public interface now uses the platform’s green-first visual identity, icons, responsive layout, Urdu/Arabic RTL readiness, visible focus, reduced-motion and forced-colors support. Public reading remains open for approved records; all mutations remain authenticated and capability-bound.
